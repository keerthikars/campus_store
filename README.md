# 🏪 Campus Store Inventory Management System

A modern web-based inventory management system designed for campus stores and college canteens. The application helps administrators manage products, categories, stock levels, sales records, and inventory reports through an intuitive dashboard.

---

## 📖 Project Overview

The **Campus Store Inventory Management System** simplifies the process of tracking and managing store inventory. It enables administrators to maintain product details, monitor stock availability, record transactions, and generate reports.

The project is built using **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Supabase**.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/campus-store-inventory.git
```

### 2. Navigate to the Project Folder

```bash
cd campus-store-inventory
```

### 3. Install Dependencies

```bash
npm install
```



## ▶️ Running the Project

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

## 🔄 Workflow

1. User logs into the system.
2. Administrator adds product categories.
3. Products are created and assigned to categories.
4. Inventory stock is updated.
5. Sales transactions are recorded.
6. Dashboard displays inventory statistics.
7. Reports can be exported for analysis.
